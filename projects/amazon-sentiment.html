Problem

A controlled NLP comparison of TF-IDF classical models against Word2Vec deep sequence models, with shared preprocessing, validation-based model selection and a held-out final test.

Contribution

The important part is the fairness of the comparison. Reviews are cleaned once, 3-star ratings are removed as ambiguous, every model sees the same task definition, and model selection happens on validation data before the final test set is used. The notebook therefore answers whether added model complexity earns better sentiment performance under a common protocol.

Result

Logistic Regression and Linear SVM are compared with TextCNN, LSTM and CNN-LSTM sequence models.

Design takeaway

Controlled comparison: the study keeps label definition, preprocessing and data splits shared across model families, so differences are attributable to the modelling approach rather than different inputs.

How the system is structured

Engineering depth

  • Controlled comparison: the study keeps label definition, preprocessing and data splits shared across model families, so differences are attributable to the modelling approach rather than different inputs.
  • Imbalance-aware selection: macro-F1, balanced accuracy and negative-class F1 drive model selection; accuracy is treated as supporting evidence.
  • Training-only feature selection: chi-square selection sits inside the training path, avoiding the common leakage error of selecting vocabulary using the full dataset.
  • Limited winner-only tuning: the workflow avoids sweeping every model until one happens to win, which makes the final comparison easier to defend.
  • Explainability on both families: classical coefficients and local DL explanations make the comparison about behaviour as well as scores.
