Problem

A modular Angular 17 application combining authenticated recipe management, a shopping-list workflow, reactive forms, RxJS state and HTTP-backed persistence.

Contribution

This is a frontend architecture exercise rather than a single-screen demo. Recipes, authentication and shopping-list concerns are separated into feature areas, with routing, guards, interceptors, forms and persistence coordinated through Angular services.

Result

The project uses a recent Angular generation with TypeScript and RxJS 7.

Design takeaway

What this demonstrates

  • Feature-oriented Angular structure: authentication, recipes, shopping list and shared UI are organised as separate modules and folders.
  • Routing beyond basic navigation: child routes, route protection and resolver-style loading support the application flow.
  • Forms for real domain editing: nested ingredient collections are managed with Angular reactive-form primitives rather than ad-hoc DOM state.
  • Service-mediated data flow: components delegate authentication, recipe state, shopping-list state and persistence to injectable services.
  • Test-ready component structure: component specification files are present throughout the major features.
