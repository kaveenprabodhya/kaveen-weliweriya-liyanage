Problem

A routed movie-rental frontend with authenticated administration, HTTP service boundaries, request/error interceptors and unit-test structure across components and services.

Contribution

The project demonstrates the infrastructure around a multi-view Angular application. Movie, customer, rental, registration, login and administration flows are connected through routing and reusable services rather than kept as isolated UI screens.

Result

Administrative navigation is protected through a dedicated AuthGuard service.

Design takeaway

What this demonstrates

  • Protected route design: administrative functionality is separated from public navigation through a route guard.
  • Cross-cutting HTTP concerns: authentication and error behaviour are implemented once through interceptors.
  • Reusable service layer: UI components consume domain-specific services instead of coupling directly to network calls.
  • Multi-domain interface: movies, customers, rentals and user management create a richer application flow than a single-resource CRUD screen.
  • Testing discipline: unit-test files mirror the major application components and services.
