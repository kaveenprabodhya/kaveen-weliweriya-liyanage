Problem

How the system is structured

Engineering depth

  • Schema-based event boundary: Avro gives the stream an explicit message contract and keeps producers/consumers from silently drifting apart.
  • Back-pressure-aware alternative: the reactive query service provides a non-blocking WebFlux path alongside the conventional servlet implementation.
  • Identity integrated at service level: JWT audience and role handling are mapped into Spring Security rather than delegated only to a front-end gateway.
  • Service startup is coordinated: compose stacks and readiness scripts wait for configuration and topics instead of assuming every dependency is instantly available.
  • External dependency isolation: interchangeable live and mock stream runners keep the pipeline runnable even when the upstream data source is unavailable.
  • Central configuration: shared configuration modules and a dedicated config repository prevent each service from carrying unrelated duplicated settings.
  • Containerised infrastructure: Docker Compose definitions separate Kafka, Elasticsearch, Keycloak and application services while preserving a repeatable local topology.
