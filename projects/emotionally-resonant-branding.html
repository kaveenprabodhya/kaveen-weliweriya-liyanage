Emotionally Resonant Branding

A full-stack research prototype that generates brand imagery, observes the viewer's facial-emotion response, and connects that response back to the specific generated asset.

Problem

How can audience emotional responses inform AI-generated brand imagery for music artists?

Contribution

Built an affective branding prototype combining image generation, facial-emotion inference, and real-time feedback; evaluated the system in a participant study.

Result

The project includes a study with 191 participants and a published 2024 research paper. The client, backend, and publication are linked below.

Design takeaway

A working prototype and a participant study answer different questions: technical integration demonstrates feasibility, while human evaluation examines usefulness, trust, and acceptance.

The project closes an affective feedback loop: a user provides a branding brief and colour direction, the system generates candidate imagery, webcam frames are analysed with a trained facial-emotion model, and the detected response is attached to the asset that produced it. That turns generative branding from a one-way content generator into an interaction loop that can be studied empirically.

How the system is structured

Engineering depth

  • Integrated model orchestration: the backend coordinates image generation, image persistence and emotion inference instead of exposing unrelated AI demos.
  • Authentication and ownership: passwords are hashed, JWTs protect API routes, and generated batches are associated with the authenticated user before deletion or retrieval.
  • Asynchronous emotion analysis: frame inference is submitted to a worker executor so emotion processing does not have to block the entire request path.
  • Traceable feedback: generated images are grouped into batch identifiers and stored with metadata, allowing the reaction to be tied to the exact generation event.
  • Research validation: the software was used as the instrument for an empirical study with 191 participants, which is a much stronger signal than an untested UI prototype.
