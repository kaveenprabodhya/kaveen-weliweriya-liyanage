How it is structured

What this demonstrates

  • SecurityFilterChain configuration: authorization rules are expressed alongside HTTP method/path matchers rather than scattered through controller logic.
  • Custom authentication boundary: the RestHeaderAuthFilter demonstrates how Spring Security can be extended for API-specific credentials.
  • Negative-path testing: the test suite checks unauthorized and invalid-credential requests, not only successful cases.
  • Security integrated with application layers: the demo secures both REST endpoints and traditional MVC flows.
